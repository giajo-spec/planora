# Photos des recettes

Déposez ici les photos nommées selon l'identifiant de la recette, par exemple :

- `poulet-tikka.jpg`
- `shakshuka.webp`

Formats acceptés : `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`. Format conseillé : 1200 × 900 px (4:3).

Le manifeste `src/lib/data/image-manifest.json` est régénéré automatiquement par
`npm run dev` et `npm run build`. Une recette sans photo affiche un visuel de
remplacement généré (jamais d'image cassée). N'utilisez pas d'images hébergées sur des sites tiers.
